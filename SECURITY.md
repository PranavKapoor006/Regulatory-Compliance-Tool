# Security and data handling

- Never commit `backend/.env`, API keys, client policies, uploaded registers, or generated assessments.
- Gemini features are optional and disabled by default. Enable them only after confirming approved data-handling requirements.
- Treat every generated obligation, finding, evidence match, and recommendation as review assistance. A qualified compliance professional must approve outputs before use.
- Report suspected credential exposure privately to the repository owner; do not open a public issue containing the secret.
